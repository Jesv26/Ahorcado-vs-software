# Ahorcado-vs-software
Un juego del ahorcado centrado en trivia sobre la ingenieria de software hecho en Godot 4.7. El juego consta de 33 preguntas (11 por dificultad) y 15 niveles (5 por dificultad).
Las preguntas están agrupadas por dificultad (facil, intermedio y dificil) en 3 .json distintos
El juego termina cuando se completán los 15 niveles o si el jugador pierde todas sus vidas. 
Elegir una letra que no se encuentre en la palabra, adivinar la palabra erroneamente o tardarse demasiado restara una vida al jugador.
El temporizador que resta vidas es de 25 segundos, se reinicia cada vez que se agota, se intenta adivinar un caracter o la palabra completa, o si el nivel es completado.
Se recuperan todas las vidas despues de completar un nivel.
